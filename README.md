# WIL Project 37 – Victorian Rental Rights Assistant

## Project Overview

This project aims to develop and evaluate a Retrieval-Augmented Generation (RAG) assistant that helps Victorian renters quickly find accurate, source-grounded information about common rental rights and responsibilities using authoritative tenancy documents.
