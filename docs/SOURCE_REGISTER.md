## Selection Criteria

The sources were selected because they:

- are published by Consumer Affairs Victoria;
- are relevant to Victorian residential renting;
- cover common renter rights and responsibilities;
- provide authoritative information suitable for RAG retrieval;
- allow source traceability and attribution;
- form a manageable initial knowledge base for evaluation.

## Source Verification

The selected sources were reviewed as authoritative Victorian Government rental information sources.

Source URLs, access dates and source metadata are retained in the corresponding knowledge-base files.

The project also distinguishes current rental rules from future-dated legislative changes where relevant, reducing the risk of using outdated or not-yet-effective information.
