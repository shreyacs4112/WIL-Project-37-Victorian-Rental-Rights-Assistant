# Evaluation and Testing

This folder contains the evaluation resources for the Victorian Rental Rights Assistant.

## Evaluation Objectives

The evaluation will focus on:

- Retrieval effectiveness
- Answer correctness
- Faithfulness to retrieved evidence
- Source attribution
- Out-of-knowledge-base / unanswered-question behaviour

## Planned Evaluation Process

1. Prepare a ground-truth set of rental-rights questions.
2. Record the expected relevant knowledge-base chunks for each question.
3. Evaluate BM25 and dense retrieval using Top-K retrieval metrics.
4. Test generated RAG answers once the full pipeline is integrated.
5. Record correctness, faithfulness, source attribution and refusal behaviour.
6. Compare results across different RAG configurations.
